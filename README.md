## 📋 Overview

A sophisticated real-time object detection system leveraging YOLOv8 (You Only Look Once) architecture to identify and track multiple objects simultaneously across images, videos, and live webcam feeds. This project implements state-of-the-art computer vision techniques for accurate, high-performance object detection in various environments.

## ✨ Features

- **Multi-Object Detection**: Simultaneously identify 80+ different object classes
- **Real-Time Processing**: Optimized for live webcam feeds with adjustable speed settings
- **Video Analytics**: Process and analyze recorded footage with object tracking
- **Image Analysis**: Static image detection with bounding box visualization
- **Performance Metrics**: Real-time FPS counter and object detection statistics
- **Adaptive Processing**: Slow-mode option for enhanced accuracy in complex scenes
- **Confidence Scoring**: Visual percentage indicators for detection reliability

## 🛠️ Technology Stack

- **Core Framework**: YOLOv8 (Ultralytics)
- **Computer Vision**: OpenCV 4.x
- **Programming Language**: Python 3.8+
- **Dependencies**: NumPy, PyTorch, Matplotlib
- **Version Control**: Git
